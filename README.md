# Tueri Systems Daily Risk Brief

Public host for the **Tueri Systems Daily Risk Brief** — a free operational intelligence podcast.

This repository is intended to serve:

- Podcast RSS (`feed.xml`) for Apple Podcasts, Spotify, and other directories
- Episode audio
- Short written show notes / episode pages

**Status:** Repository is public for hosting setup. Directory submission (Apple / Spotify) and public show launch remain held until Tueri authorizes release.

Website: [tuerisystems.com](https://tuerisystems.com)  
Contact: contact@tuerisystems.com

## Layout

```
feed.xml          Podcast RSS (GitHub Pages raw/public URL once enabled)
episodes/         Per-episode show notes (YYYY-MM-DD.md)
audio/            Episode MP3s referenced by the feed
assets/           Cover art and other public media
docs/             Listener-facing notes only (no internal production playbooks)
```

## Notes

- Internal production materials (source registry, correction register, playbooks) stay off this repo.
- Do not treat an empty or staging feed as a live directory listing until release is authorized.
